## 记录规则

- 每次记录实验日期、代码版本、数据集及版本、样本量、配置、指标、耗时和原始结果位置。
- 保留历史结果；配置或数据变化后新增实验，不覆盖旧分数。
- 未测项目写 `null / 未测`；中断、错误和未通过的结果也保留。工程测试通过数不代表模型质量。
- 金额区分供应商 API 账单与本机资源成本；不把未返回的用量或费用当成零。
- 私有原文、问题、密钥和联系邮箱不写入此文件。原始逐题产物保存在 Git 忽略目录。

## 1. M1 检索基线：2026-10-16

数据：`qasper-v0.3-dev-40`，40 篇论文、1,892 个片段、40 道问题；其中 32 道有标注证据、8 道在限定论文内无答案。质量指标只计算前 32 道，延迟统计全部 40 道。使用公开开发集，已用于诊断，不能作为未见最终测试集或 M8 人工 Gold。

配置：应用检索链路、SQLite FTS5 / Qdrant；BGE `BAAI/bge-small-en-v1.5`，384 维；旧版 `source_index.build_chunks`，每片段最多 1,200 字符；Hybrid 为单查询 RRF，Top 10。原文来自 QASPER/S2ORC，未经过 M2 PDF 解析器。

| BM25 | 0.78125 | 0.78125 | 0.348996 | 0.447931 | 3.98 | 4.87 |

| Hybrid | 0.78125 | 0.78125 | 0.384462 | 0.477571 | 709.75 | 817.09 |

耗时包含 Trace，Dense/Hybrid 另含本地查询向量生成及 Qdrant；不含索引构建。三组顺序运行，不能据此断言 Hybrid 比 Dense 更快。Hybrid 比 BM25 的 MRR、nDCG 高，Recall 相同，32 道可回答问题仍有 7 道未召回标注证据。各模式原始报告均为 `quality_gate_met=false`。
